# Thesis #50: Closed-Atmosphere Pharmaceutical Stability on the Lunar Surface

**Author:** Kelechi Emeka Ogbonna
**Affiliation:** Independent computational research / Project Confluence
**Date:** September 2026

## Overview
This repository contains Thesis #50, a computational research manuscript investigating the accelerated degradation kinetics of essential medicines under reduced gravity and elevated radiation on the lunar surface. The study utilizes a modified Arrhenius model incorporating a radiation co-factor and a 14-day thermal cycling period to predict the shelf-life of critical pharmaceutical agents (beta-lactams, epinephrine, acetaminophen) for lunar missions.
